# Capturas del sistema de gestión de peluquería desarrollado en entorno de consola utilizando Python y base de datos SQLite.

Esta carpeta contiene evidencia visual del funcionamiento del sistema, mostrando sus principales módulos y operaciones CRUD.

🔹 Gestión de Clientes
Alta de clientes (INSERT)  
Listado de clientes (SELECT)  
Edición de datos (UPDATE)  
Eliminación de registros (DELETE)

🔹 Gestión de Servicios
ABM completo (Alta, Baja, Modificación)

🔹 Gestión de Turnos
Registro y administración de turnos  
Relación entre clientes y servicios mediante consultas SQL JOIN

🔹 Base de datos
El sistema utiliza consultas SQL para la manipulación y relación de datos:

SELECT (consulta y muestra datos de la base de datos)    
INSERT (inserta nuevos registros en la base de datos)
UPDATE (modifica registros existentes) 
DELETE (elimina registros de la base de datos) 
JOIN (relación entre tablas clientes y servicios en el módulo de turnos)
