# Documentación técnica del sistema de gestión de peluquería.

El sistema está desarrollado en Python utilizando SQLite como base de datos relacional.

🔹 Arquitectura del sistema:
- Aplicación de consola en Python
- Manejo de base de datos SQLite local
- Lógica separada por funciones para clientes, servicios y turnos

🔹 Funcionamiento general:
- CRUD completo para clientes, servicios y turnos
- Uso de consultas SQL para la gestión de datos
- Relación entre tablas mediante JOIN

🔹 Tecnologías utilizadas:
- Python
- SQLite
- SQL
